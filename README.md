# PocoManualCam

Manual Camera app for Poco M6 Pro 4G (and similar devices with Camera2 LEVEL_3 support).

## Features (Current)
- Manual ISO
- Manual Shutter Speed
- Manual Focus
- Live preview using Camera2 API
- Pure hardware control (no AI)

## Requirements
- Android 8.0+
- Camera2 API LEVEL_3 recommended

## Status
Early development version.
